# Lexicon — Frontend

React 19 + Vite SPA for the Lexicon collaborative wiki app.

## Development

```bash
npm install
npm run dev      # dev server at http://localhost:5173
```

The dev server proxies `/api` requests to the backend at http://localhost:5149.

## Build & Lint

```bash
npm run build    # production build → dist/
npm run lint     # ESLint
```
